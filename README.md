# Staff Leave Management System 

A complete, responsive web application designed to streamline the leave application and approval process for college departments. Built using core PHP and MySQL, this system replaces manual paperwork with a centralized digital dashboard.

##  Key Features

* **Role-Based Access Control:** Distinct interfaces and permissions for Staff members and Heads of Department (HOD).
* **Dual-Role HOD Dashboard:** HODs can seamlessly apply for their own leave while simultaneously managing and reviewing their staff's pending requests.
* **Automated Balance Tracking:** The system automatically calculates leave days and deducts them from specific quotas (Paid, Unpaid, Medical) only upon HOD approval.
* **Real-Time "Absent Today" Snapshot:** A prominent dashboard feature that instantly displays which staff members are currently on approved leave for the day.
* **Application History Logs:** Comprehensive tracking of all past and pending requests for transparency.
* **Modern UI:** Clean, card-based interface styled with custom CSS and FontAwesome icons.

## Technologies Used

* **Frontend:** HTML5, CSS3, Font Awesome Icons
* **Backend:** PHP (Vanilla)
* **Database:** MySQL
* **Development Environment:** XAMPP

## Installation & Setup Guide

Since this is a PHP/MySQL application, you will need a local server environment like XAMPP, WAMP, or MAMP to run it.

### Prerequisites
1. Download and install [XAMPP](https://www.apachefriends.org/index.html).
2. Ensure **Apache** and **MySQL** modules are running in the XAMPP Control Panel.
